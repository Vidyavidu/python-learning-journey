#  Python Functions Notes

##  1. Defining a Function
- A function is a reusable block of code designed to perform a specific task.
- Functions help organize code into smaller, manageable sections.
- They improve readability, maintainability, and code reuse.
- A function executes only when it is called.
- Functions reduce code duplication by allowing the same logic to be used multiple times.

---

##  2. Function Parameters
- Parameters are variables that receive values when a function is called.
- They allow functions to work with different inputs.
- Parameters make functions more flexible and reusable.
- A function can have one, multiple, or no parameters.
- The values passed to parameters are called arguments.

---

##  3. Returning Values from a Function
- Functions can send results back to the caller using a return value.
- Returning values allows the output of a function to be stored, displayed, or used in further calculations.
- A function may return one value, multiple values, or no value.
- Once a return statement is executed, the function ends immediately.

---

##  4. Default Parameter Values
- Default parameters provide predefined values for function parameters.
- If no argument is supplied during the function call, the default value is used.
- They make function calls simpler and more flexible.
- Default values help avoid errors caused by missing arguments.
- Parameters with default values are optional when calling the function.

---

##  5. Local and Global Variables

### Local Variables
- Local variables are created inside a function.
- They can only be accessed within that function.
- They exist only while the function is executing.
- Used for temporary data needed by a specific function.

### Global Variables
- Global variables are defined outside all functions.
- They can be accessed from different parts of a program.
- They remain available throughout the program's execution.
- Useful for data that needs to be shared across multiple functions.

### Variable Scope
- Scope refers to the area where a variable can be accessed.
- Local variables have limited scope.
- Global variables have broader scope.
- Understanding scope helps prevent naming conflicts and errors.

---

##  Summary
- Functions are reusable blocks of code that perform specific tasks.
- Parameters allow functions to accept input values.
- Return values enable functions to send results back.
- Default parameters provide optional values for flexibility.
- Local variables exist only inside functions.
- Global variables can be accessed throughout the program.
- Proper use of functions improves code organization and reusability.
