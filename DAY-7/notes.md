#  Python Conditional Statements Notes

##  1. The if Statement
- The `if` statement is used to make decisions in a program.
- It executes a block of code only when a specified condition is true.
- It helps control the flow of a program based on different situations.
- If the condition is false, the code inside the `if` block is skipped.

---

##  2. The else Statement
- The `else` statement is used along with the `if` statement.
- It executes a block of code when the condition in the `if` statement is false.
- Provides an alternative path for program execution.
- Ensures that one of the two blocks is executed.

---

##  3. The elif Statement
- The `elif` statement stands for "else if".
- It is used to check multiple conditions one after another.
- If the first condition is false, the program checks the next condition.
- Multiple `elif` statements can be used in a single decision structure.
- Helps handle multiple possible outcomes efficiently.

---

##  4. Comparison Operators in if Statements
- Comparison operators are used to compare two values.
- They return either `True` or `False`.
- Common comparisons include:
  - Equal to
  - Not equal to
  - Greater than
  - Less than
  - Greater than or equal to
  - Less than or equal to
- Frequently used in conditional statements to make decisions.

---

##  5. Logical Operators in if Statements
- Logical operators are used to combine multiple conditions.
- They work with Boolean values (`True` and `False`).
- Types of logical operators:
  - **AND** → True only if all conditions are true.
  - **OR** → True if at least one condition is true.
  - **NOT** → Reverses the result of a condition.
- Useful for creating complex decision-making logic.

---

##  6. Nested if Statements
- A nested `if` statement is an `if` statement placed inside another `if` statement.
- Used when multiple levels of conditions need to be checked.
- Allows more detailed decision-making.
- Can make programs more powerful but should be used carefully to maintain readability.

---

##  Summary
- `if` executes code when a condition is true.
- `else` executes code when the condition is false.
- `elif` helps check multiple conditions.
- Comparison operators are used to compare values.
- Logical operators combine multiple conditions.
- Nested `if` statements allow multi-level decision making.
